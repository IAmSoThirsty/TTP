# TTP - Thirsty's Texture Packs

A curated collection of tailored texture packs for IAmSoThirsty repositories, supporting projects from miniature office pixel art to VR cinematics and AI-driven experiences.

## Overview

This repository provides high-quality, organized texture packs designed for various projects in the IAmSoThirsty ecosystem. Each texture pack is carefully crafted to match specific project requirements and visual styles.

## Available Texture Packs

### 1. Miniature Office Pixel
Located in `packs/miniature-office-pixel/`

A pixel-art texture pack designed for miniature office environments. Perfect for indie games, pixel art projects, and retro-styled applications.

**Features:**
- Low-resolution pixel-perfect textures
- Office furniture and equipment
- Interior design elements
- Optimized for 2D and isometric views

### 2. VR Cinematics
Located in `packs/vr-cinematics/`

High-quality textures optimized for virtual reality cinematic experiences. Designed for immersive storytelling and interactive VR content.

**Features:**
- High-resolution textures (4K+)
- PBR (Physically Based Rendering) materials
- Optimized for VR performance
- Cinematic lighting-ready

### 3. Project AI
Located in `packs/project-ai/`

Specialized texture pack for AI-driven projects, featuring futuristic and tech-themed assets.

**Features:**
- Tech and sci-fi themed textures
- UI/UX elements for AI interfaces
- Data visualization assets
- Modern and futuristic design language

## Usage

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/IAmSoThirsty/TTP.git
   ```

2. Navigate to the desired texture pack:
   ```bash
   cd TTP/packs/[pack-name]
   ```

3. Copy the textures to your project's asset directory.

### Pack Structure

Each texture pack follows this structure:
```
packs/[pack-name]/
├── pack.json          # Pack metadata and configuration
├── README.md          # Pack-specific documentation
├── textures/          # Texture files
├── materials/         # Material definitions (if applicable)
└── previews/          # Preview images
```
